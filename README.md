## 🚀 طريقة الرفع والنشر على GitHub Pages في دقيقتين:

### الطريقة الأولى: عبر متصفح الويب (الأسهل بدون أوامر)
1. افتح حسابك على موقع [GitHub](https://github.com/).
2. أنشئ مستودعاً جديداً (New Repository) وسمّه بالضبط:
   `mosttkbal.github.io`
   *(اجعل المستودع **Public**)*.
3. اضغط على **"uploading an existing file"** واسحب جميع ملفات هذا المجلد:
   - `index.html`
   - `style.css`
   - `script.js`
   - `.nojekyll`
   - مجلد `assets/` (يحتوي على الشعار `logo.jpg` والصورة `hero.jpg`)
4. اضغط **Commit changes**.
5. اذهب إلى تبويب **Settings** في المستودع > من القائمة الجانبية اختر **Pages**.
6. في قسم **Branch** تأكد من اختيار `main` ثم المجلد `/ (root)` واضغط **Save**.
7. خلال دقيقة سيصبح موقعك متاحاً ويعمل رسمياً على:
   **`https://mosttkbal.github.io`**
